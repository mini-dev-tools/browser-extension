Privacy Policy

Mini Dev Tools Chrome Extension & Web App

Last Updated: March 6, 2025

Your Privacy Matters

At Mini Dev Tools, we are committed to protecting your privacy. This privacy policy explains how our Chrome extension and web application handle your data.

🔒
100% Local Processing

All tools process data locally in your browser. Nothing is sent to external servers.

🚫
No Data Collection

We don't collect, store, or track any personal information or usage data.

🛡️
No Analytics

We don't use Google Analytics or any other tracking services.

Information We Don't Collect

Mini Dev Tools is designed with privacy-first principles. We do NOT collect:

  • Personal identification information
  • Usage statistics or analytics
  • Input data from any tools
  • Browsing history or activity
  • IP addresses or location data
  • Device information
  • Cookies or tracking identifiers

How Our Tools Work

All Mini Dev Tools functionality operates entirely within your browser:

Color Tools

  • Color picking, palette generation, and contrast checking happen locally
  • Saved palettes are stored in your browser's local storage
  • No color data is transmitted externally

Text & Utility Tools

  • Text processing, encoding/decoding, and generation occur in-browser
  • Generated passwords, UUIDs, and hashes are created locally
  • No input or output data leaves your device

File Operations

  • File downloads are generated directly in your browser
  • Uploaded files (e.g., for Swagger viewer) are processed locally
  • Files are never uploaded to any server

Chrome Extension Permissions

Our Chrome extension requires certain permissions to function. Here's why we need each one:

Required Permissions

  • activeTab: To interact with the current tab for features like color picking
  • tabs: To manage browser tabs for the window resizer tool
  • windows: To resize browser windows
  • downloads: To save generated files to your computer
  • storage: To save your preferences and tool settings locally
  • contextMenus: To provide right-click functionality
  • scripting: To inject color picker functionality
  • desktopCapture: For screenshot functionality

Important: These permissions are only used for the described functionality. We never use them to collect or transmit data.

Local Storage

Mini Dev Tools uses your browser's local storage to:

  • Save your tool preferences and settings
  • Store custom color palettes
  • Remember your recent colors and tool history
  • Cache tool states for better user experience

This data never leaves your device and can be cleared at any time through your browser settings.

Third-Party Services

Mini Dev Tools does NOT use any third-party services for:

  • Analytics or tracking
  • Advertising
  • Data processing
  • Cloud storage
  • External APIs

Data Security

Since all processing happens locally in your browser:

  • Your data never travels over the internet
  • There's no risk of server breaches affecting your data
  • You have complete control over your information
  • Clearing browser data removes all stored information

Children's Privacy

Mini Dev Tools is a general-purpose developer tool and does not knowingly collect information from children under 13 years of age.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated revision date. Since we don't collect user data, we cannot notify you directly of changes, so we encourage you to review this policy periodically.

Open Source Transparency

Mini Dev Tools is committed to transparency. Our code is open source, allowing anyone to verify our privacy practices by examining the source code directly.
